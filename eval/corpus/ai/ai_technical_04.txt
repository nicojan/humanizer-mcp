JavaScript is the programming language of the web browser. If a web page does anything beyond just sitting there, chances are JavaScript is behind it. When you click a button and a menu slides open, when a form warns you about a missing field before you hit submit, when new posts load as you scroll without the page reloading, that's JavaScript at work.

It helps to see where it fits. A web page is built from three technologies that each do a different job. HTML provides the structure, the headings and paragraphs and buttons. CSS handles how everything looks, the colors, fonts, and layout. JavaScript adds the behavior, the part that responds to what you do. In this article we'll unpack what JavaScript actually is, what it lets you build, and why it became the language that makes the web interactive.
