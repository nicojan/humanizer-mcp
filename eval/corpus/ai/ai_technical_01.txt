Git can feel intimidating before you've actually used it, but the core idea is simple: it keeps a complete history of your project so you can experiment freely and never lose work. In this tutorial, you'll learn the two ways every project begins. The first is starting fresh, where you take a folder on your own machine and turn it into a Git repository with a single command. The second is cloning, where you grab a copy of a project that already exists somewhere else, usually a service like GitHub, and bring the whole thing down to your computer with its full history intact.

Knowing which one you need is half the battle, and beginners mix them up all the time. By the end, you'll be comfortable telling the two apart, and you'll have done both yourself. You'll create a brand-new repository from scratch, clone an existing one, and understand what's actually happening on disk in each case. No prior Git experience required, just a terminal and a few minutes.
