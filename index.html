The checker runs on every keystroke, entirely in your browser, and flags what a fixed rule can find: the openers and em-dashes that block outright, then the flagged words, rhetorical tics, and flat rhythm to clear. It is the same engine the MCP server ships, ported to run with no server and no network.

The checker returns findings and fixes; it never rewrites the text. That judgment stays with the writer. Severity colours follow Apple's Human Interface Guidelines. Document-level findings (rhythm, section variation, list density) apply to the whole draft and carry no inline mark.
